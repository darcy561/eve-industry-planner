# Import Fit Dialogue

The Import Fit dialogue allows you to import ship fittings from your clipboard, automatically creating jobs for all items in the fitting.

## Overview

The Import Fit dialogue provides:
- Clipboard import functionality
- Ship fitting parsing
- Automatic job creation
- Quantity multiplier support

## Key Features

### Clipboard Import

- Import fittings from clipboard
- Support for EVE fitting formats
- Automatic item detection
- Error handling for invalid formats

### Fitting Parsing

- Parse ship fittings
- Extract all items
- Identify quantities
- Handle modules and charges

### Job Creation

- Automatically create jobs for items
- Set quantities from fitting
- Apply quantity multipliers
- Group related items

### Quantity Multiplier

- Multiply quantities by a factor
- Useful for multiple fits
- Adjust item counts
- Preview before import

## Usage

1. Copy a ship fitting to your clipboard
2. Open the Import Fit dialogue
3. Grant clipboard permissions if needed
4. Review imported items
5. Set quantity multiplier if needed
6. Import to create jobs

## Permissions

The Import Fit dialogue requires clipboard read permissions. You may need to grant these permissions in your browser when first using this feature.
