# Shopping List Dialogue

The Shopping List dialogue generates a comprehensive list of all materials needed for selected jobs, helping you plan material acquisition efficiently.

## Overview

The Shopping List dialogue allows you to:
- Generate shopping lists from selected jobs
- View all required materials in one place
- See quantities needed across multiple jobs
- Export or copy shopping lists
- Import materials from assets or clipboard

## Key Features

### Material Aggregation

- Combines materials from multiple jobs
- Shows total quantities needed
- Groups materials by type
- Displays item icons and names

### Asset Integration

- Import materials from your assets
- See what you already have available
- Calculate remaining materials needed
- Filter by asset location

### Location Selection

- Select asset locations to check
- View materials by character
- View materials by corporation
- Filter by station or structure

### Clipboard Import

- Import materials from clipboard
- Support for various formats
- Quick material entry
- Batch import functionality

## Usage

1. Select jobs in the Job Planner
2. Click "Shopping List" from the menu
3. Review the generated list
4. Import from assets or enter manually
5. Export or copy the list as needed
