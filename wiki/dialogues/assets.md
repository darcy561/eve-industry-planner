# Assets Dialogue

The Assets dialogue displays all your assets for a specific item type, allowing you to view quantities, locations, and use assets in your jobs.

## Overview

The Assets dialogue shows:
- All instances of a specific item across your characters
- Asset locations (stations, structures, ships)
- Quantities available at each location
- Character and corporation ownership

## Key Features

### Asset Display

- View assets by item type
- See all locations where items are stored
- Display quantities per location
- Show character and corporation information

### Location Information

- Station locations
- Structure locations (citadels, etc.)
- Ship locations
- Filter by location type

### Asset Usage

- Select assets to use in jobs
- Import assets to shopping lists
- Link assets to material requirements
- Track asset utilization

### Character and Corporation Assets

- View character assets
- View corporation assets
- Filter by ownership
- See asset distribution

## Usage

1. Click on an item or material in a job
2. Select "View Assets" or similar option
3. Review available assets and locations
4. Select assets to use or import
5. Apply assets to your job or shopping list
