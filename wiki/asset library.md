# Asset Library

The Asset Library displays all your assets from EVE Online, including items stored in stations, structures, and ships across all your characters and corporations.

## Overview

The Asset Library allows you to:
- View all your assets
- Search and filter assets
- See asset locations
- Track asset quantities
- Use assets when planning manufacturing and reaction planner jobs

## Key Features

### Asset Display

- View assets by character
- View assets by corporation
- Filter by location
- Search by item name

### Asset Information

- See item name and icon
- View quantity available
- Check location details
- See asset value

### Asset Usage

- Use assets when planning manufacturing and reaction planner jobs
- Import assets to shopping lists
- Link assets to planner jobs
- Track asset utilization

### Asset Locations

- View assets by station
- See assets in structures
- Check assets in ships
- Filter by location type
