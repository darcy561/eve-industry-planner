# Dashboard

The Dashboard provides an overview of all your industry operations, including account data, active jobs, transactions, and watchlists.

## Overview

The Dashboard gives you:
- Quick overview of all operations
- Account and character information
- Recent transactions
- Item watchlists
- Active job summaries

## Key Features

### Account Data

- View linked accounts and characters
- See character slots and information
- Monitor account status
- Manage account connections

### Recent Transactions

- View latest market transactions
- Track recent sales
- Monitor financial activity
- Review transaction history

### Item Watchlists

- Create watchlists for items
- Monitor item prices
- Track market trends
- Set up price alerts

### Character Slots

- View character information
- See active industry jobs per character
- Monitor character activity
- Manage character assignments
