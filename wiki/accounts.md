# Accounts

The Accounts page allows you to manage your EVE Online accounts and characters, configure ESI access, and control which characters have access to the application.

## Overview

The Accounts page provides:
- Account and character management
- ESI authentication setup
- Character access control
- Account information display

## Key Features

### Account Management

- View all linked accounts
- Add new accounts
- Remove accounts
- Configure account settings

### Character Management

- View characters per account
- See character information
- Manage character access
- Configure character permissions

### ESI Integration

- Set up ESI authentication
- Configure API access
- Manage API tokens
- Control data access permissions

### Additional Accounts

- Add secondary accounts
- Link multiple accounts
- Manage account relationships
- Configure account priorities
