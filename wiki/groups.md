# Groups

Groups allow you to organize related industry jobs together for better management, scheduling, and tracking of complex manufacturing projects.

## Overview

Groups help you:
- Organize related jobs into logical collections
- Schedule job execution
- Track group progress
- Manage complex manufacturing chains
- View aggregated statistics

## Key Features

### Creating Groups

- Create new groups from selected jobs
- Create empty groups and add jobs later
- Organize jobs by project, item type, or purpose
- Name and configure groups

### Group Management

- Add jobs to existing groups
- Remove jobs from groups
- Reorganize groups
- Delete groups when no longer needed

### Scheduling

- Schedule job execution
- Plan manufacturing timelines
- Coordinate related jobs
- Use Gantt view for timeline visualization

### Group Views

- Classic view with detailed job cards
- Compact view for overview
- Accordion layout for organization
- Filter and sort options
