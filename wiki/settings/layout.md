# Layout Settings

The Layout Settings section allows you to customise the visual appearance and user interface behaviour of Eve Industry Planner.

## Available Options

### Enable Help Cards

**Toggle:** Enable/Disable Help Cards

When enabled, help cards and tutorial information will be displayed throughout the application to guide you through various features. Disable this option if you're already familiar with the interface and want a cleaner view.

- **Enabled:** Help cards and tutorials are shown
- **Disabled:** Help cards are hidden

### Enable Compact View

**Toggle:** Enable/Disable Compact View

Compact view reduces the spacing and padding throughout the application, allowing you to see more information on screen at once. This is particularly useful for users with smaller displays or those who prefer a more information-dense interface.

- **Enabled:** Compact spacing is applied throughout the application
- **Disabled:** Standard spacing is used

## How Settings Are Saved

All layout settings are automatically saved to your account with a 2-second debounce delay. This means:
- Changes are saved automatically after you stop making adjustments
- No manual save button is required
- Settings are synced across all your devices
