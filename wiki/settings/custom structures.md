# Custom Structures

Custom structures are saved presets the planner uses to calculate industry jobs. They are not live ESI structure links—they are combinations of structure type, rig(s), tax, system type, and solar system that match what you actually use in game.

## Where you control it

- Settings → Custom Structures tab
- First-login setup — Optional structure step when you first configure the app

## Choose a structure type

At the top, select which activity you are configuring: Manufacturing, Reaction, Invention, or Reprocessing.

The form and Current Structures list below update for that type. Switching type does not delete other types—you maintain separate lists per activity.

## Adding a structure

After you pick a type, fill in the fields and add the preset. Display name is your label only; it does not need to match an in-game structure name.

Press Add to save the preset to Current Structures for the selected activity type.

Different rigs in game give bonuses to specific item types. The app does not differentiate between those item types—it applies the bonus from the rig level only, because the bonus is the same across all rig variants of that level. If you use structures that are bonused for some items and not others, create two custom structures (one with rig bonuses, one without) and assign each where it applies.

## Current Structures list

Saved presets appear as cards below the form.

Each card summarises the fields that matter for that activity—structure type, rig(s), tax, security, system and index (manufacturing/reaction), or implant (reprocessing).

| Action | Effect |
|--------|--------|
| Make Default | New jobs (and the reprocessing calculator for reprocessing type) start with this preset when they need a default structure |
| Remove | Deletes the preset from your account; jobs already using it may show “Missing Structure” until you reassign |

Only one default per activity type at a time. The default card is marked accordingly. Click Make Default on another card to switch. The first preset you add for a type becomes default automatically; if you remove the default, the first remaining preset is marked default.

## Where presets are used

- [Edit Job — Setups](../edit%20job/planning/setups) — Assign a saved preset to a setup, or use built-in defaults per system type.
- [Job Settings](../settings/job) — Citadel Brokers Fee Percentage for broker fees on market orders in player-owned structures (Selling stage)
- [Reprocessing Calculator](../reprocessing%20calculator) — Loads the default reprocessing preset; you can change structure on the page for one-off runs.
