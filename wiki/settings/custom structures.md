# Custom Structures

The Custom Structures section allows you to add and manage custom structures for manufacturing and reprocessing jobs. This is essential for accurately calculating job costs and times when using player-owned structures.

## Overview

Custom structures include:
- **Manufacturing Structures:** Engineering Complexes, Citadels, and other structures used for manufacturing
- **Reaction Structures:** Structures used for reactions
- **Reprocessing Structures:** Structures used for reprocessing ores and ice

Each structure type has different bonuses, material efficiency, and time efficiency values that affect job calculations.

## Adding Custom Structures

### Step 1: Select Job Type

First, choose the type of job you want to configure structures for:
- **Manufacturing:** Structures for building items from blueprints
- **Reactions:** Structures for running reactions
- **Reprocessing:** Structures for reprocessing raw materials

### Step 2: Select Structure Type

After selecting a job type, choose the specific structure type you want to add:
- Engineering Complexes (various sizes)
- Citadels
- Upwell Structures
- Other specialised structures

### Step 3: Configure Structure Details

For each structure, you can configure:
- **Structure Name:** A custom name to identify the structure
- **Material Efficiency:** The material efficiency bonus (affects material costs)
- **Time Efficiency:** The time efficiency bonus (affects job duration)
- **Location:** The system and location of the structure

### Step 4: View Current Structures

Once you've added structures, they will appear in the Current Structures list. You can:
- View all configured structures for each job type
- Edit existing structure configurations
- Remove structures that are no longer in use

## Structure Types

### Manufacturing Structures

Manufacturing structures are used for building items from blueprints. Different structure types offer different bonuses:
- **Engineering Complexes:** Provide material and time efficiency bonuses
- **Citadels:** Offer various bonuses depending on the citadel type
- **Upwell Structures:** Specialised structures with specific bonuses

### Reaction Structures

Reaction structures are used for running reactions. These structures have specific bonuses for reaction jobs.

### Reprocessing Structures

Reprocessing structures are used for reprocessing ores and ice into refined materials. These structures have reprocessing efficiency bonuses.

## Managing Structures

### Current Structures List

The Current Structures section displays all structures you've configured, organised by job type. You can:
- See all structures at a glance
- Identify which structures are configured for which job types
- Access structure editing options

### Best Practices

1. **Keep Structures Updated:** Regularly update structure configurations if bonuses change
2. **Use Descriptive Names:** Name your structures clearly to identify them easily
3. **Remove Unused Structures:** Clean up structures that are no longer in use
4. **Verify Bonuses:** Double-check that material and time efficiency values are correct

## How Settings Are Saved

Custom structure configurations are saved automatically and synced across all your devices.
